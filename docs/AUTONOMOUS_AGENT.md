# 自主排障助手

在案件详情页的“自主排障助手”中输入问题，点击“开始自主分析”。

- 一般解释可直接回答，例如“429 和超时有什么区别”。页面会显示“本轮直接回答，未调用工具”。
- 需要案件证据时，模型选择读取附件、识别截图、检查规则或检索知识库；它也可以根据工具结果继续选择下一步。
- 工具执行记录显示实际执行、失败与拦截情况，不将工具调用失败解释为没有匹配证据。
- 查询 new-api 日志前，在账号区填写并确认客户用户名。未确认时，日志工具不会注册给模型；更换账号会取消当前请求、清空对话并要求重新确认。
- 生成的报告与自由回答均待人工核对。对话仅保留在当前页面，不写入正式诊断历史，不改变案件及审核状态；需要正式留档时，运行原有深度诊断并人工审核。

## 实现

`POST /api/cases/:id/agent` 校验问题和有限的用户/助手历史，加载当前案件 Trace 与附件元数据，并在服务端绑定工具上下文。客户端不能上传工具结果、系统消息、文件路径或任意证据集合。对话历史中的分析不能替代实际读取的证据。

`src/lib/tool-agent.ts` 使用 `ChatOpenAI.bindTools()`：常规决策采用 `tool_choice: auto`，模型可以返回工具调用，也可以返回普通回答。LangGraph 在 `think` 与 `act` 节点之间按工具调用结果循环。工具顺序执行，参数先经 Zod 校验；没有开放的工具、无效参数及超出预算的调用不会执行。工具错误会作为明确的失败观察返回，原始异常和凭证不会发送给模型或浏览器。

继续沿用百炼密钥、兼容接口地址及 `QWEN_ANALYSIS_MODEL`，所选模型需要支持工具调用。Qwen 决策请求关闭思考模式；报告生成继续使用现有模型适配层。没有新增外部服务或数据库表。

## 工具与服务端约束

| 工具                           | 自主助手中的参数与边界                                               |
| ------------------------------ | -------------------------------------------------------------------- |
| `read_diagnosis_text_evidence` | 仅当前案件已脱敏附件 ID；每轮最多五份文本                            |
| `extract_diagnosis_images`     | 仅当前案件批准的图片 ID；每轮最多五张图片                            |
| `run_diagnosis_rules`          | 无参数，读取服务端 Trace 和本轮实际提取的文本、图片                  |
| `search_diagnosis_knowledge`   | 经校验的检索词及可选厂商；返回来源与片段                             |
| `generate_diagnosis_report`    | 无参数，基于服务端实际证据生成报告，强制执行规则、引用校验及结论裁定 |
| `validate_diagnosis_evidence`  | 无参数，检查本轮最新报告；证据更新后旧报告失效                       |
| `search_request_logs`          | 仅在人工确认账号后开放；只能选择时间与分页，不能替换账号与已确认条件 |

报告生成即使未被模型单独要求校验，也会强制通过引用校验和结论裁定。未读取或失败的附件会列入阻断项，Agent 不能将其内容当成已知事实。日志查询结果仅为候选，不会自动写入案件证据或确认请求；应回到请求定位入口人工核对后导入。

## 预算与取消

每轮最多六次决策模型调用、八次模型选择的工具调用。最后一轮决策或工具预算耗尽时，采用 `tool_choice: none` 让模型收束回答；模型仍尝试调用时不会执行。

服务端还为每轮设置十二次总模型请求预算，使用独立的异步上下文计数，包含决策、图片识别、报告生成、格式修复及提供商重试。并发用户请求各有独立预算，不共享计数。预算耗尽时不再发送模型请求，返回需补充信息或缩小范围的提示。

日志工具另外限制六次查询和五百条预留记录预算，失败请求同样消耗预算。除已确认的精确请求标识查询外，每次必须提供不包含未来且跨度不超过十五天的时间范围。读取的日志不会提升为已确认的案件证据。

整个请求受服务端总超时约束，取消信号传递到图、模型和工具。模型可见的工具输出预览限制长度；用于校验和报告生成的实际证据仍留在服务端，预览截断不会变成新的事实。

## 验证

测试覆盖零工具回答、按需选择、工具结果反馈、未知工具、无效参数、调用上限、模型忽略 `tool_choice: none`、取消执行、嵌套模型请求预算、伪造证据拦截、报告失效、日志范围及分页预算。数据库集成验证案件上下文绑定和不改变审核状态；浏览器验证直接回答、后续工具调用、账号确认及更换账号清空对话。普通测试使用合成模型及日志响应，不调用真实客户模型或日志接口。
